Afghan MD Job Assistant

See the repository README.md for installation, profile setup, workflow, sources, and safety rules.

Core workflow

  1. Complete My Profile with verified medical facts.
  2. Upload a CV.
  3. Find Afghanistan medical jobs.
  4. Review deterministic eligibility: Required → Met / Not met / Needs verification.
  5. Prepare CV and cover letter drafts.
  6. Open the real application page.
  7. Submit only after explicit confirmation.
  8. Track follow-up and outcomes.
